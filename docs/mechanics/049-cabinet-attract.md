# Cabinet attract sequence and self-playing demonstration

- Mechanic: CAB-01 — the attract cycle an idle cabinet plays: title → self-playing demonstration → best-five high-score table → a second demonstration → title, running forever until a credit starts a real game, with no scoring or life loss anywhere in the cycle. Two-player alternation (CAB-03) and live high-score initials **entry** (CAB-04) are deliberately out of scope; this slice delivers the one-player attract loop, its auto-pilot demo, and the static default best-five table only.
- Derived behavior: On power-on the arcade enters the attract cycle at the title stage and dispatches the current stage through a four-slot jump table indexed by `attract_mode_stage − 1`, so stage 2 is the title, stages 1 and 3 are two separate demonstration passes sharing one handler, and stage 4 is the best-five table — the cycle is title → demo → best-five → demo → title, **two demos per lap**. The title stage runs a fixed 744-frame script (a 64-frame hold, then a 16 + 136 + 16 sparkle intro, then a 512-frame parity-gated flashing logo) and then advances to a demonstration. The demonstration has no timer: it plays the real game with an auto-pilot at the controls and exits only when the demo craft is destroyed and the death sequence disables scrolling. The auto-pilot draws its movement from the same shared pseudo-random generator the game uses, holding a chosen direction for sixteen arcade frames and re-drawing it only when the frame counter's low nibble is zero, rejecting-and-redrawing any draw of nine or more so it keeps a value 0–8 where direction 8 means "hold still", and it fires whenever an independent draw's low nibble is zero (one chance in sixteen); because both draws come from the seeded generator, a demo replayed from the same seed traces an identical path. The best-five stage runs 512 frames (sixty-four updates on every eighth frame) showing the top five default scores and initials. Crucially, **no score or life state is touched anywhere in the attract dispatch** — the score bytes are cleared and the starting lives installed only on the credited-start path — so a demonstration neither scores nor spends a craft; when the demo craft is hit it simply ends the demo. (The demo handler does set its own area, enemy-AI level, and scroll counter to run area 1, so "untouched" is score-and-life, not area/scroll.) The 1UP/2UP HUD indicator shows **steady** during attract and **flashes only during a real game** — the arcade blanks it on alternating timer phases only when the real-game flag is set, so a cleared flag (attract) disables the flash. The hidden bonus-credit ground object is silently removed while attract is active.

Epoch-guarded `director enter` handlers implement the title hold (~372 ticks ≈ 744 frames at `FRAMES_PER_TICK=2`) and the scores hold (~256 ticks ≈ 512 frames). A virtual input register (`input up/down/left/right/fire`) is read through a boolean-composed `input_active(dir)` reporter — `(attract==1 AND variable) OR (attract==0 AND key_pressed)` — dropped into the six keyboard reads in the player and blaster sprites, so a demo drives itself and a real game reads the keyboard unchanged. `install_attract_pilot`, called first in the ordered walk under `if attract==1`, reproduces `gen_rnd_dir`/`gen_rnd_shot` against the shared RNG at a fixed draw-order position for reproducibility. `install_score` is wrapped in `if attract==0` (one path suppresses both score and bonus craft), `death_check`'s attract branch ends the demo without spending a craft or routing to game-over, and the Game-Start fanfare is gated on `attract==0`. ## Update (presentation slice, CAB-05)

Deviation (3), **music during the demo**, is reversed ([record 055](055-presentation-fidelity.md)). The arcade mutes every sound when it enters its
attract cycle with no credit banked (`main_thread_main_loop` 355–356 in `src/xevious_main.68k`) and unmutes at
`coined_up` (379–380), and it never requests the flight tune or the death cue in a demo (2009, 2028–2030). The
Stage — the owner of every game sound — is now silent while `attract` is 1 and no credit is banked, and the flight
tune, start theme and death cue are gated on `attract` = 0. The coin sound is the one cue heard from the attract
cycle: it plays once the credit it announces has lifted the mute. The `start_sound` gate named in the Scratch
evidence above is now the `attract` = 0 gate on the Stage's start-theme and flight-tune script.

The attract cycle above now runs only with no credit banked. The arcade checks the credits before it enters
the cycle and goes straight to `coined_up` when one is banked (`main_thread_main_loop` 353–354), which waits for
START and never runs a demo. The port's title and best-five holds used to launch their demos whatever the credit
count, so after a coin — or after a game that ended with credits left — a demo ran, and with sound. Both holds
now launch a demo only at 0 credits; with a credit in, the title stays up until START (record 055 deviation (17)).
