Third-party content vendored into this directory
================================================

Two files here are not this project's work. They are committed rather than downloaded so that
meaning-based recall runs offline, needs no artifact fetcher in the engine's runtime, and can be
verified byte-for-byte against the hashes in checksums.json.


potion-retrieval-32m-int8.npz
-----------------------------
A quantized copy of the word table from minishlab/potion-retrieval-32M, a static embedding model
published by the Minish Lab under the MIT License. The upstream file is a float32 table; the copy
here stores each row as int8 with a float32 scale, which is a derivative of the original and carries
the same licence and obligations. checksums.json records the upstream file's own sha256, the
quantization rule, and the resulting shape, so the derivation can be checked or repeated.

The authors ask that use of the model be cited:

    The Minish Lab, "Model2Vec: Distilling Static Embedding Models"
    https://github.com/MinishLab/model2vec
    https://huggingface.co/minishlab/potion-retrieval-32M

vocab.txt
---------
The WordPiece vocabulary the table is keyed by. It is not the Minish Lab's own work: potion-retrieval-32M
is distilled from BAAI/bge-base-en-v1.5 and inherits that model's tokenizer, so this file's provenance
and licence are BAAI's. bge-base-en-v1.5 is published under the MIT License.

    BAAI General Embedding, https://huggingface.co/BAAI/bge-base-en-v1.5

It is vendored as vocab.txt rather than the publisher's tokenizer.json because only the vocabulary is
needed: the tokenizer pipeline itself is implemented in wordpiece.py from the standard library, and its
output is verified against the reference implementation.
